# Alpha Lab データ更新

米国株リサーチ用ページ「Alpha Lab」のデータを、Claude を使わずに取得する仕組みです。サイト本体（main）には含まれません。

## Google Apps Script（ページが使う方式）

`apps-script/Code.gs`（第5版）を自分の Google アカウントの Apps Script に貼り付けて動かします。

1. https://script.google.com でプロジェクトを開き（初めてのときだけ新しく作る）、`Code.gs` の中身を全部貼り付けて保存する
2. 関数「setup」を実行し、権限を許可する

新しい版に貼り替えるときは、新しいプロジェクトを作らずに、setup で名前が「Alpha Lab 更新スクリプト」になったプロジェクトに貼り替えて、setup を実行し直します。
同じスクリプトが2つ以上動くと、ページの依頼を取り合って更新できなくなるためです（第4版までで起きていました）。第5版は次のようにして防ぎます。

- 更新を受け持つのは、最後に setup したプロジェクト1つだけ（`alab-owner.json`）。ほかのプロジェクトに残った第5版は、自分のトリガーを消して止まる。受け持ちのプロジェクトが30分以上動いていなければ、残っている第5版が代わりに受け持つ
- ファイル名を第4版までと変えている（`alab-status.json`・`data5/`・`alab-req.json`・`alab-config.json`・`alab-universe.json`）。第4版までの古いプロジェクトが動き続けていても、依頼やデータは混ざらない
- 初めて動いたときに、第4版までのデータ（`data/`）を `data5/` に写し（ハッシュは中身から計算し直す）、古い状態ファイル `alpha-lab-status.json` をゴミ箱に移す。古い `data/` は `data-old` に名前を変える（動作を確かめたら削除してかまいません）。古い状態ファイルがなくなると、古いプロジェクトは銘柄の一覧が読めずに何も取得しなくなる
- 古いプロジェクトだけが拾う依頼ファイル（`alpha-lab-request.json`、中身は何もしない ping）を置いて、古いプロジェクトがまだ動いているかを確かめ、状態ファイルの `old` に書く。ページはそれを見て「トリガーを削除してください」と案内する

以後は1分ごとに自動で動き、次のことをします。

- ページの更新ボタンが「Alpha Lab データ」フォルダに置いた依頼ファイル（`alab-req.json`）を読み、その種類の更新を実行する。受け付けた依頼は状態ファイルの `acc` に書く（ページは自分の依頼が受け付けられたかをこれで確かめる）
- 火〜土の朝（日本時間 6:40〜7:00）に、株価・スコア・アナリスト評価を自動で更新する
- 結果を同じフォルダの `data5/` に gzip＋base64 の JSON で保存し、`alab-status.json` に一覧とハッシュを書く。何もないときも10分ごとに状態ファイルを書き直し、動いていることをページに知らせる

ページは Google Drive コネクタで `alab-status.json` を読み、変わったデータだけをページのデータベースへ写します（第5版がまだないときは `alpha-lab-status.json` を読み、貼り替えの手順を案内します）。

アナリスト評価の更新では、決算日・EPS予想の修正・決算サプライズ（`meta/earn`）と、今後2週間の決算と米国の経済指標の予定（`meta/cal`）も Yahoo Finance から取ります。

メール通知: ページの「メール通知」の設定とウォッチリストは `alab-config.json` としてドライブに置かれ、Apps Script が読みます。
毎朝の更新のあとと、米国市場の取引時間中は15分ごとに、価格アラート・大きな値動き・52週高値/安値・格上げ/格下げ・目標株価の変化・決算の前日・EPS予想の修正を判定し、まとめて1通のメールで知らせます。
依頼ファイルの `add` に書かれた銘柄（ページに新しく加わった銘柄）は、以後の更新対象に加わります。

そのほか、毎回の更新のあとに次のものを保存します。

- `meta/signals`: 全銘柄のテクニカルのシグナル（ゴールデンクロス・デッドクロス・52週高値/安値・200日線の上抜け/下抜け・RSI・出来高急増）
- `meta/own`: 空売り比率・インサイダーの売買・機関投資家の保有（アナリスト評価の更新で取得）
- `hist/YYYY-MM-1|2`: 取引日ごとのスコア・株価・平均目標株価・推奨の平均（半月ごとのファイル）。スコアはページと同じ計算で、ページが置く `alab-universe.json`（銘柄とセクター）を使う
- `meta/pf`: モデルポートフォリオ（スコア上位20社に等金額、週に1回入れ替え）と、S&P 500・全銘柄平均との比較

## GitHub Actions（予備）

- `update.py` が Yahoo Finance・FRED・CNN・Nasdaq からデータを取り、`alpha-lab-data` ブランチに JSON で保存します（Apps Script 版と同じ形式）。
- `request.json` を書き換えると `.github/workflows/alpha-lab.yml` が動きます。
- `mode` は `quotes`（株価・チャート・マーケット指標・ニュース・経済データ・予定）、`score`、`analyst`、`all` のいずれかです。
- 銘柄一覧はブランチでは `quotes-v2.json` の名前で持ちます（第4版までの Apps Script が初回用に読む `quotes.json` を置かないため）。第5版の Apps Script は、データがないときだけ、このリポジトリの `alpha-lab/seed/quotes.json` を銘柄一覧として読みます。
